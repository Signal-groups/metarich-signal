보험법규
보험업법 · 상법 보험편 · 금융소비자보호법 핵심
보험업법 기본 구조
  • 보험업: 생명·손해·제3보험을 영위하는 사업
  • 보험회사 설립: 금융위원회 허가
  • 최저자본금: 생명보험 300억원 이상
  • 보험회사 재무건전성: 지급여력비율 100% 이상
  • 예금자보호: 1인당 5천만원(원금+이자 합산)
보험계약의 법적 성질
  • 낙성계약: 청약+승낙으로 성립 (서면 불요)
  • 유상계약: 보험료 ↔ 보험금 교환
  • 사행계약: 보험사고 발생에 따라 급부 결정
  • 최대선의계약: 고지의무 법적 근거
  • 부합계약: 보험자가 미리 작성한 약관 적용
보험계약 구성요소
  • 보험계약자: 계약체결·보험료 납입 의무자
  • 피보험자: 보험사고 대상이 되는 자
  • 수익자: 보험금 받을 자 (지정 가능)
  • 보험자: 보험금 지급 의무를 지는 보험회사
  • 타인의 생명 보험: 피보험자 서면동의 필수
고지의무
  • 계약 전 알릴 의무 = 고지의무
  • 위반 시 해지 가능: 계약일로부터 3년 이내
  • 고지의무 위반 후 2년 경과 → 해지 불가
  • 보험자가 안 경우·과실로 모른 경우 → 해지 불가
  • 인과관계 없는 사고 → 해지 가능, 보험금 지급
보험계약의 취소·무효
  • 사기 계약: 5년 이내 취소 가능
  • 무효 사유: 심신박약자·고의사고·불법이익 목적
  • 15세 미만자 사망보험: 원칙 무효
  • 보험가액 초과 보험: 초과분 무효
  • 계약 무효 시 → 보험료 반환 원칙
청약 철회권
  • 청약일로부터 15일 이내 (보험증권 받은 날 기준)
  • 청약 후 30일 이내도 철회 가능
  • 청약 철회 후 3영업일 이내 보험료 반환
  • 적용 제외: 단기보험·타인의 생명 보험
  • 이미 발생한 사고가 있는 경우 철회 불가
보험료 납입 관련
  • 납입 유예기간(grace period): 1개월
  • 유예기간 내 사고 → 보험금 지급
  • 실효 후 부활(復活): 3년 이내 가능
  • 자동대출납입: 해약환급금 범위 내 자동대출
  • 해지환급금 지급: 청구 후 3영업일 이내
금융소비자보호법 핵심
  • 6대 판매원칙: 적합성·적정성·설명의무·불공정거래금지·부당권유금지·광고규제
  • 적합성 원칙: 소비자 재산·성향에 맞는 상품 권유
  • 위반 시 청약 철회: 5영업일 이내
  • 자료 보존: 10년
  • 분쟁조정 신청: 금융감독원, 한국소비자원
【출제 포인트】 고지의무 위반 해지 가능 기간(3년/2년), 청약 철회(15일/30일), 타인의 생명 보험계약 시 피보험자 서면동의는 반드시 암기!

생명보험 기초
생명보험 원리 · 보험료 구조 · 언더라이팅
생명보험의 특성
  • 사람의 생사를 보험사고로 하는 인보험
  • 실손보상 아님 → 정액지급 원칙
  • 이득 금지 원칙 적용 안 됨 (중복 보험 가능)
  • 피보험이익: 사람의 생명·신체에 대한 경제적 이익
  • 순수보장형·저축형·혼합형으로 구분
보험료 3원칙 구조
  • 영업보험료 = 순보험료 + 부가보험료
  • 순보험료 = 위험보험료 + 저축보험료
  • 부가보험료 = 신계약비 + 유지비 + 수금비
  • 예정사망률: 사망 확률 → 보험료 산정 기준
  • 예정이율: 운용수익률 → 높을수록 보험료 저렴
  • 예정사업비율: 사업비 가정 → 낮을수록 보험료 저렴
생명표(사망표)
  • 보험개발원이 작성·공표
  • 경험생명표: 보험회사 실제 사망 데이터 기반
  • 국민생명표: 통계청 전국 데이터 기반
  • 여성이 남성보다 사망률 낮음 → 보험료 낮음
  • 개정 주기: 5년마다 갱신
언더라이팅(보험심사)
  • 표준체: 일반적인 사망위험 수준
  • 표준미달체: 위험이 높아 표준 요율 불가
  • 우량체(비흡연자·건강체): 보험료 할인
  • 역선택(Adverse Selection) 방지 목적
  • 고지의무·진단 등으로 위험도 평가
해약환급금·해지
  • 해약환급금 = 적립된 저축보험료 - 해지공제
  • 초기 해지 시 원금 손실 발생
  • 계약자 대출: 해약환급금 80~90% 이내
  • 해지 후 재가입: 건강 상태 등 새로 심사
  • 적립이율: 공시이율 적용 시 변동 가능
보험금 청구·지급
  • 지급 기한: 청구서류 수령 후 3영업일 이내
  • 지급 조사 필요 시: 최대 10영업일 연장
  • 분쟁 등 사유 시: 30영업일 이내 지급
  • 지연 시 지급지연이자 가산
  • 소멸시효: 보험금 청구권 3년

종신보험
  • 사망 시점 관계없이 반드시 사망보험금 지급
  • 상속설계·유족보장 목적에 적합
  • 보험료 납입 완료 후 유지 가능
  • 순수보장형: 해약환급금 거의 없음
  • 저축형 포함 시 환급 가능
연금보험
  • 노후 소득 보장 목적
  • 연금개시 나이: 보통 만 55세 이상
  • 연금 종류: 확정연금·종신연금·상속연금
  • 세제적격: 연금저축보험 (소득공제)
  • 세제비적격: 저축성보험 (비과세 조건 충족 시)
CI(치명적 질환)보험
  • 중대한 질병(암·뇌졸중·심근경색 등) 진단 시 지급
  • 사망보험금을 선지급하는 구조
  • 선지급 후 사망보험금은 그만큼 감액
  • 보장 정의 엄격 → 일반 암과 다를 수 있음
  • GI(중증질환)보험: CI보다 넓은 보장 범위
건강(질병·상해)보험
  • 제3보험에 해당 (생명+손해 겸영 가능)
  • 실손의료보험: 실제 의료비 보상
  • 암보험: 암 진단금·치료비 지급
  • 어린이보험: 출생~성인 전환 보장
  • 갱신형: 일정 기간마다 보험료 재산정

모집인 의무 및 규제
보험모집 규정 · 금지행위 · 설명의무
보험모집 자격
  • 보험설계사: 금융감독원에 등록
  • 보험대리점: 금융위원회에 허가 (법인)
  • 보험중개사: 금융위원회에 허가
  • 보험회사 임직원: 별도 등록 불요
  • 자격취득 후 교육 이수 의무
설명의무 핵심
  • 중요사항을 이해할 수 있도록 설명
  • 설명확인서(설계사 서명): 의무
  • 청약서 부본 교부: 의무
  • 보험증권 교부: 30일 이내
  • 계약 전 알릴 의무 설명·기재 의무
금지행위 (절대 암기)
  • 허위·과장 설명 금지
  • 보험료 대납·할인 금지
  • 특별이익 제공 (한도 초과 선물 등) 금지
  • 부당한 계약 전환 (승환계약) 금지
  • 미확정 사항 확정 표현 금지
통신판매(TM) 규정
  • 전화 등으로 청약 가능 (대면 불요)
  • 녹취 의무 (청약·설명 과정)
  • 청약 철회: 15일 이내
  • 자필서명 대체: 음성 녹음 또는 전자서명
  • 고령자·취약계층 보호 강화 규정 적용
