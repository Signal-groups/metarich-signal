숨은보험금 찾기

고객이 받을 수 있는 미청구 보험금을 조회합니다. 첫 접근 시 고객의 흥미를 즉각 끌어내는 강력한 도구입니다.

이런 때 사용 👉 "보험금 못 받은 게 있을 수도 있어요" 멘트와 함께 사전 접근 시
주의: 크롬에서 접속 권장, 링크 복사 후 주소창에 직접 입력
사전접근 초회면담
🏥

진료기록 확인

건강e음 어플을 활용해 고객의 진료 이력을 확인하는 방법을 안내합니다. 고지의무 및 현재 건강 상태 파악에 활용합니다.

이런 때 사용 👉 고객 고지의무 확인, 기존 질환·수술 이력 파악 시
포인트: 직접 공유보다 고객이 직접 확인하게 안내
초회면담 사실확인
💊

약학정보원

고객의 복용 약을 검색해 성분·부작용·보험 가입 시 영향을 확인합니다. 가입 가능 여부 및 고지 필요 여부 판단에 사용합니다.

이런 때 사용 👉 "드시는 약이 있으세요?" 질문 후 약 이름 검색 시
포인트: 예시 항암약 아닌지, 성분 확인
사실확인 제안
📋

내보험 바로 알기

고객이 가입된 보험을 한 번에 파악하고 보장 공백을 찾는 캠페인 도구입니다. 기존 보험 리뷰 상담의 시작점으로 활용합니다.

이런 때 사용 👉 "지금 가입된 보험이 뭔지 정확히 아세요?" 질문과 함께
포인트: 보장 공백 발견 → 자연스러운 리뉴얼 제안으로 연결
사전접근 초회면담
💳

고객상담 카드

카드를 선택해 고객에게 맞는 보험이 설계되었는지, 필요한 것은 무엇인지 확인합니다. 상담의 방향을 잡는 전략 도구입니다.

이런 때 사용 👉 상담 초반, 고객 니즈 파악 및 우선순위 정리 시
포인트: 카드별 핵심 질문으로 대화 방향 설정
초회면담 사실확인
📢

보험상품 공시

각 보험사 상품 약관 공시를 바로 확인합니다. 상담 중 약관 내용, 면책 조항, 지급 기준 질문에 즉시 대응할 수 있습니다.

이런 때 사용 👉 "이 담보 정확히 어떻게 지급되나요?" 질문 시
포인트: 회사별·상품별 공시 링크 직접 연결
제안 클로징

보장별 통계 자료

암·뇌·심장·치매 등 질환별 통계 이미지를 상담 근거로 제시합니다. 고객이 필요성을 느끼지 못할 때 객관적 근거를 보여줍니다.

이런 때 사용 👉 "굳이 이게 필요한가요?" 반응을 보일 때
카테고리 선택 → 키워드 검색 → 이미지 팝업 확대 제시
초회면담 사실확인 제안
🔄

보험료 비교

건강보험·종신·저축성 회사별 보험료와 담보 차이를 비교합니다. 제안 방향을 잡고, 고객에게 합리적 선택을 안내합니다.

이런 때 사용 👉 특정 회사·상품이 왜 좋은지 설명할 때
상품 선택 → 질환 검색 → 회사별 비교 결과 제시
사실확인 제안 클로징
🏢

회사별 간편 인수 확인

고객 병력·수술 이력에 따른 회사별 간편심사 기준을 빠르게 확인합니다. 상담 중 "가입 가능한가요?" 질문에 즉시 답변 가능합니다.

이런 때 사용 👉 고지사항이나 기왕증 있는 고객 상담 시
질환 검색 → 회사별 인수 기준 비교

사이드바 주요 메뉴

  • 홈: 메인 고객 상담 도구 화면으로 돌아옵니다.
  • 사무실 업무: 실적 입력, 교육 관리, 업무 달력 (프로 사용자)
  • 고객 CRM: 고객 정보 관리, 보장 분석, PDF 리포트
  • 자료 검색: 보험 관련 자료 키워드 검색 🔍
  • 자격시험 모의고사: 4개 과목 모의고사 허브 (NEW)
  • 고객 DM 발송: 이미지 DM 제작 및 발송
  • 보험의 기준 카페: 네이버 카페 바로가기
  • 보험의 기준 오픈채팅: 카카오 오픈채팅 참여

프로 사용자 가이드

시그널그룹 소속 설계사를 위한 사무실 업무 전용 기능을 안내합니다.
실적 관리, 교육 이수, 고객 CRM, DM 발송 등 설계사의 일상 업무를 시스템화합니다.

🔒 시그널그룹 소속 설계사 전용 · 관리자 승인 필요

💡

사무실 업무 탭 진입 방법

  • 사이드바 상단 "사무실 업무" 메뉴 클릭 (승인된 설계사 전용)
  • 또는 모바일 하단 네비바의 "업무" 탭 탭
  • 사무실 업무 탭에서는 달력, 실적 입력, 교육 관리가 통합 제공됩니다
📊 사무실 업무 핵심 기능
📅

월간 실적 입력

월별 계약 건수·금액, 통화·미팅·프레젠테이션·소개 건수를 입력하고 목표 대비 달성률을 관리합니다.

사용 방법 👉
사무실 업무 탭 → 이번 달 기록 탭 선택
목표 입력 (관리자 잠금 해제 필요) → 실적 입력 → 저장하기
포인트: 최근 3개월 평균은 사이드바 좌측 하단에 자동 표시
매일/매월
🎓

교육 이수 관리

주차별 교육 내용을 확인하고 이수 여부를 체크합니다. 관리자가 입력한 교육 커리큘럼을 확인하고 참여 현황을 기록합니다.

사용 방법 👉
사무실 업무 탭 → 교육 관리 탭 선택
주차별 교육 내용 확인 → 이수 체크박스 클릭 → 자동 저장
주간
👥

고객 CRM

고객 정보 등록, 보험 증권 업로드, 보장 분석, PDF 리포트 생성, 계약 이력 관리를 한 곳에서 처리합니다.

사용 방법 👉
사이드바 → 고객 CRM 클릭
고객 등록 → 증권 업로드 → 보장분석 → 리포트 생성
포인트: GPTs 분석 JSON 업로드로 분석 자동화 가능
상시

DM 콘텐츠 제작

설계사 이름·소속·연락처가 들어간 보험 정보 이미지를 제작합니다. 인스타그램용 4:5, DM용 9:16 규격을 지원합니다.

사용 방법 👉
사이드바 → 고객 DM 발송 클릭 → 팝업창 오픈
이미지 선택 → 문구·색상 설정 → PNG 다운로드 → 발송
주간

실적 분석 & 히스토리

월별 실적 추이, 최고·최저 달성 월, 3개월 평균을 차트와 함께 확인합니다. 성과 분석으로 영업 패턴을 파악합니다.

사용 방법 👉
사무실 업무 탭 → 달력에서 월 선택
